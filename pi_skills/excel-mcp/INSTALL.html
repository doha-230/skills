Excel MCP 폐쇄망 설치 설명서

인터넷 없이 Windows PC의 Excel을 Pi 코딩 에이전트에서 제어하기 위한 파일 구성, 설치, 검증 및 운영 범위를 안내합니다.

1. 준비 사항

  • Windows 10 이상, x64 환경, Microsoft Excel 2016 이상 데스크톱 버전.
  • Excel을 실행할 수 있는 로그인된 대화형 Windows 데스크톱. 서버 서비스나 Linux 컨테이너용 도구가 아닙니다.
  • MCP를 지원하는 Pi 코딩 에이전트와 내부에서 동작하는 모델. Pi의 내장 MCP 기능이 있는 버전을 기준으로 설명합니다.
  • 배포 ZIP을 외부에서 내려받아 폐쇄망으로 반입할 승인된 수단. 반입 후에는 npm, Node.js, .NET 설치가 필요하지 않습니다.
자연어로 Excel 데이터를 읽게 하면 MCP 도구 결과가 Pi와 Pi에 연결된 모델로 전달됩니다. 모델이 외부 API라면 폐쇄망 운영이 아닙니다. 모델의 연결 대상도 확인하세요.

2. 파일 구성과 무결성

저장소의 dist/excel-mcp-pi-offline-2.4.1-windows-x64.zip을 반입합니다. 압축을 풀면 아래처럼 구성됩니다.

excel-mcp-offline/
├─ INSTALL.html
├─ README.md
├─ PROVENANCE.md
├─ LICENSE
├─ install-pi.ps1
└─ server/
   └─ ExcelMcp-MCP-Server-2.4.1-windows.zip

내부 server ZIP은 원본 릴리스 파일을 수정하지 않은 상태입니다. 설치 스크립트가 원본 ZIP과 그 안의 실행 파일 모두 SHA-256으로 검증합니다.

검증 대상SHA-256
원본 서버 ZIP4b7be341694b603e7d2de5633ed9cd366fe246874484392935e2e2fa40e53654
ZIP 안의 mcp-excel.exe56f216c19bea45c4ff586cfaf0e4c9f8ff708503173fdc24837bedf0bb7e0ed1

배포 ZIP의 해시는 저장소에 있는 같은 이름의 .zip.sha256 파일에서 확인합니다.

Get-FileHash .\excel-mcp-pi-offline-2.4.1-windows-x64.zip -Algorithm SHA256

3. 설치

  1. 배포 ZIP을 폐쇄망 PC로 복사하고 압축을 풉니다.
  2. Windows PowerShell을 열어 install-pi.ps1가 있는 폴더로 이동합니다.
  3. 아래 명령을 실행합니다. 실행 정책 변경은 현재 PowerShell 프로세스에만 적용됩니다.
Set-ExecutionPolicy -Scope Process Bypass
.\install-pi.ps1

스크립트는 실행 파일을 %LOCALAPPDATA%\Programs\ExcelMcp\mcp-excel.exe에 복사하고, 사용자별 %USERPROFILE%\.pi\agent\mcp.json에 excel-mcp를 등록합니다. 기존 설정 파일은 날짜가 붙은 .bak로 백업한 뒤 다른 서버 항목을 유지합니다.

등록 내용에는 EXCELMCP_TELEMETRY_MODE=off가 포함됩니다. 설치가 끝나면 Pi를 다시 시작합니다.

수동 설정이 필요한 경우

Pi 설정 파일의 mcpServers 객체에 아래 항목을 추가할 수 있습니다. 경로의 사용자 이름은 실제 값으로 바꿉니다. JSON에서 백슬래시는 두 번 씁니다.

{
  "mcpServers": {
    "excel-mcp": {
      "command": "C:\\Users\\YOUR_NAME\\AppData\\Local\\Programs\\ExcelMcp\\mcp-excel.exe",
      "env": { "EXCELMCP_TELEMETRY_MODE": "off" }
    }
  }
}

이미 mcp.json에 다른 설정이 있다면 파일 전체를 위 예시로 덮어쓰지 말고 excel-mcp 항목만 추가합니다.

4. 동작 확인

  1. Pi가 실행 중이었다면 다시 시작합니다.
  2. PowerShell에서 pi mcp list를 실행하거나 Pi 안에서 /mcp를 열어 excel-mcp 연결 상태를 확인합니다.
  3. 테스트 파일을 대상으로 “새 Excel 파일을 만들고 A1에 테스트라고 써 줘”라고 요청합니다.
  4. Excel에서 파일을 열어 A1 값을 확인합니다.
파일을 저장하거나 수정하는 요청은 실제 Excel 파일에 반영됩니다. 테스트에는 복사본이나 새 파일을 사용하세요.

5. 폐쇄망 운영 범위

항목운영 기준
Excel MCP 기본 작업로컬 Excel COM API로 실행됩니다. 원본 실행 파일을 직접 실행하므로 npm 다운로드가 없습니다.
사용 통계배포판의 기본 설정은 Azure 전송을 시도할 수 있습니다. 패키지의 Pi 설정은 EXCELMCP_TELEMETRY_MODE=off를 지정합니다.
Pi 모델폐쇄망 안에서 동작하는 모델 또는 내부망 모델 엔드포인트를 사용해야 합니다.
선택 기능Python in Excel은 Microsoft 클라우드가 필요합니다. 원격 M/DAX 포맷팅과 외부 데이터 연결도 네트워크를 사용할 수 있으므로 폐쇄망에서는 사용하지 않습니다.
Excel·OfficeExcel 설치와 라이선스 활성화는 별도로 준비해야 합니다. 조직의 Office 네트워크 정책을 따릅니다.

6. 문제 해결

  • 해시 오류: 파일이 손상되었거나 다른 버전입니다. 원본 파일과 배포 ZIP을 다시 확인하세요.
  • Pi에서 연결되지 않음: pi mcp list 출력, 설치된 실행 파일 경로, mcp.json의 JSON 형식을 확인하세요. Pi의 MCP 기능이 켜져 있어야 합니다.
  • Excel 작업 실패: 해당 사용자로 Excel을 직접 열 수 있는지, 로그인된 데스크톱 세션인지 확인하세요. 열려 있는 대상 통합 문서는 저장하고 닫은 뒤 다시 시도하세요.
  • 일부 기능만 실패: DAX 쿼리 실행에는 MSOLAP 등 별도 구성 요소가 필요할 수 있습니다. 외부 연결에 의존하는 통합 문서도 연결 대상이 차단되면 새로 고침할 수 없습니다.

이 패키지는 Linux 환경에서 파일 구조와 해시를 검증했습니다. Windows Excel과 Pi의 실제 연결·작업 검증은 대상 PC에서 위 절차로 수행해야 합니다.
